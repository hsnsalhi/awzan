# زليج الأوزان

أوزان الأفعال العربية ومشتقاتها في القرآن الكريم، مرسومة جدارًا من الزليج.

- **الجدار**: كل جذر نجمة عشرية، وكل بتلة وزن من الأوزان العشرة. البتلة الملوّنة فعلٌ ورد في القرآن، والمنقّطة صيغة قياسية لم ترد.
- **مرشّح الأوزان** (أسفل الشاشة): اختر وزنًا لترى انتشاره في الجذور ومعانيه وقوالبه.
- **النجمة المفتوحة**: انقر على جذر لتفتحه: الفعل في كل وزن، تشريحه (حروف زائدة / حروف الجذر)، الآية، والمشتقات (المضارع، المصدر، اسم الفاعل، اسم المفعول) مع ما ورد منها في القرآن.
- **تحدٍّ**: استنتج الوزن أو المعنى أو قالب الاسم من الآية.

موقع ثابت بلا أدوات بناء. البيانات في `js/data.js`، والصرف في `js/morph.js`.
منشور على GitHub Pages من فرع `gh-pages`.
