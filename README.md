# مِصْهَر الأوزان

تطبيق ويب لفهم أوزان الأفعال العربية في القرآن الكريم.

- **المِصْهَر**: اختر جذرًا، ثم قالبًا (وزنًا)، واصبب حروف الجذر في القالب لتخرج الفعل مع معناه والآية التي ورد فيها، ثم قارنه بأفعال أخرى على الوزن نفسه.
- **الشبكة**: جدول الجذور × الأوزان العشرة، الخانات المضيئة أفعال واردة في القرآن.
- **الاختبار**: استنتج الوزن أو المعنى من الآية.

موقع ثابت بلا أدوات بناء: افتح `index.html`. البيانات في `js/data.js`.
