# زليج الأوزان

أوزان أفعال القرآن الكريم ومشتقاتها، مرسومة جدارًا من الزليج.

🔗 **الموقع:** <https://hsnsalhi.github.io/awzan/>

- **الجدار**: ٩٤١ جذرًا ورد منها فعل في القرآن، في ألواح بحسب الحرف الأول. كل جذر نجمة عشرية، وكل بتلة وزن من الأوزان العشرة: الملوّنة وردت في القرآن، والمنقّطة صيغة قياسية لم ترد، والمعتمة لا تُصاغ. حجم النجمة بعدد مواضع أفعالها.
- **مرشّح الأوزان** (أسفل الشاشة): اختر وزنًا لترى انتشاره في الجذور، ومعانيه وقوالبه، وكل أفعاله ومشتقاته في القرآن.
- **النجمة المفتوحة**: الفعل في كل وزن، تشريحه (زائد / أصلي)، صيغه الواردة وآياته كلها (نصّ تنزيل)، المشتقات (المضارع، المصدر، اسم الفاعل، اسم المفعول) مع ما ورد منها، ومادّة الجذر في مقاييس اللغة والمفردات.
- **تحدٍّ**: استنتج الوزن أو المعنى أو قالب الاسم من آية.
- رابط مباشر لجذر ووزن: `#كبر/10`.

## المصادر والتراخيص

البيانات مأخوذة من مشروع [غابة الجذور](https://github.com/hsnsalhi/roots):

| المصدر | الاستعمال | الترخيص |
|---|---|---|
| [Quranic Arabic Corpus](https://corpus.quran.com) v0.4 (جامعة ليدز) | الجذور، الأفعال وأوزانها، الصيغ، المواضع، المشتقات | GNU GPL |
| [تنزيل](https://tanzil.net) — الرسم العثماني 1.1 | نصّ الآيات (منقول حرفيًا) | CC BY 3.0 |
| ابن فارس، مقاييس اللغة؛ الراغب، المفردات — عبر OpenITI | مادّة الجذر | ملك عام |

صيغ المشتقات غير الواردة تُولَّد قياسًا (`js/morph.js`)، والشروح المختصرة لبعض الأفعال في `js/data.js` اجتهادية.

## إعادة توليد البيانات

```bash
git clone --depth 1 https://github.com/hsnsalhi/roots ../roots
python3 scripts/build_data.py ../roots   # يكتب data/wall.json و data/roots و data/quran
```

موقع ثابت بلا أدوات بناء؛ للتجربة محليًا: `python3 -m http.server` ثم افتح `http://localhost:8000`.
